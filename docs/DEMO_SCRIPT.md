## 0. Hook (60초) — 화면 열기 전

> **말로만.** "오늘 발표 시작하기 전에 질문 하나 드리겠습니다. 로봇청소기를 자동 모드로 켜놨다가, 결국 답답해서 꺼본 적 있으신가요?
>
> 저희가 이 프로젝트를 시작한 동기가 그겁니다. **사용자는 AI 자율성을 원하지만 동시에 그걸 못 믿어서 결국 수동으로 돌아갑니다.** 자율성의 병목은 청소 성능이 아니라 **'왜?'에 답하지 못하는 신뢰 격차**입니다.

→ 화면 공유 시작, `https://cleaning-context.vercel.app/` 로딩.

## 1. 첫 화면 — 포지셔닝 + 방법론 (90초)

페이지 로드 후 스크롤하지 말고 **헤더 + Methodology 카드**에서 멈춤.

> "이건 스탠드얼론 청소 AI가 아닙니다. **LG ThinQ 옆에 그대로 얹을 수 있는 디바이스 측 explainable decision layer** 입니다. LG는 데이터·하드웨어를 이미 갖고 있고, 빠진 건 결정·이유를 만드는 layer 뿐입니다.
>
> 그 layer를 5단계로 명세했습니다."

`Methodology` 카드의 **5-Layer 다이어그램** 한 번 짚으면서:
- "공간 → 사용자 행동 → 상황 추론 → **결정** → **이유 설명**"
- "여기서 중요한 건 결정과 설명을 분리한 것입니다."

`Rule-based vs LLM` 비교표 1~2초 짚기:
> "점수 계산은 **결정론적 알고리즘**이 합니다. 같은 입력엔 매번 같은 결과. LLM은 그 점수표를 자연어로 해석하기만 합니다. **점수 계산엔 LLM이 절대 관여하지 않습니다** — '그냥 GPT 붙인 거 아니냐'는 비판을 차단합니다."

## 3. 시나리오 1 — 비 오는 날 귀가 (90초) — **핵심 시연**

스크롤 내려 평면도 + 시나리오 카드. **"비 오는 날 귀가"** 클릭.

→ ~2초 후 결과 렌더링.

평면도 가리키며:
> "20:30, 비, 사용자가 방금 귀가했습니다. **현관이 가장 진하게(우선순위 1위, 65점), 침실은 빗금 처리(제외)**. 한눈에 보입니다."

`AI 설명` 카드 본문 짚으면서:
> "왜 이렇게 결정했는지 — '비가 와서 현관 오염 가능성이 높고, 사용자가 방금 귀가했기 때문에 현관을 우선 청소. **침실은 취침 시간이 가까워 소음을 줄이기 위해 제외**'."

**"왜?" 토글** 열어서 점수 breakdown 보여주기:
> "이게 단순 자연어가 아닙니다. 점수표에 근거를 둔 설명입니다 — 현관 +20(비), +15(귀가) / 침실 -30(취침 2시간 이내)."

`더 묻기` 추천 질문 중 **"왜 거실이 우선이 아니야?"** 클릭:

→ ~3초 후 답변. 읽을 시간 ~5초.

> "이렇게 사용자가 추가 질문을 해도 LLM이 같은 점수표를 근거로 답합니다 — 점수를 다시 계산하지 않고, 맥락 언어로만."

> "이게 저희가 말한 **'상황 맥락'** 입니다 — 시간이라는 하나의 변수가 모든 결정을 뒤집습니다."

## 시연 중 주의사항

- **시나리오는 1·3만**: 4개 전부 보여주면 늘어짐. 1번(가장 임팩트) + 3번(대비 효과)만 라이브, 2·4는 멘토 질문 시 추가 시연.
- **Custom 모드 응답은 ~3-5초**: preset처럼 즉시 안 옴 (LLM cache 미사용). 멘토에게 "직접 입력은 라이브 LLM이라 잠시 걸립니다" 한마디.
- **글자 크기**: HouseMap 영역은 화면 공유 시 작아 보일 수 있음. 시연 전에 브라우저 줌 110%로.
- **"더 묻기" 답변 등장까지 ~3초**: 침묵 깨려면 "지금 LLM이 점수표 보고 답을 만들고 있습니다" 한마디.

## 라이브 실패 시 fallback

- 시나리오 응답이 5초 넘게 안 오면 → 로컬 서버(http://localhost:3001)로 즉시 전환
- 그것도 실패하면 → 백업 영상 (3주차 P2-11에서 녹화 예정 — 멘토 미팅까지는 아직 없음, 정 안 되면 PLANNING.md §4의 데모 시나리오 표를 띄워 말로 설명)

## Q&A 반박 대응 — PLANNING §15 인용

- "LG가 직접 하면 되지 않나?" → 본체 대체가 아니라 도메인 특화 layer **제안**. 멘토링 트랙의 정합한 결과물.
- "중앙 허브 오면 다 무의미?" → 지연·프라이버시·도메인 지식·오프라인 fallback. 디바이스 측 결정·설명은 남는다.
- "그냥 GPT 붙인 거?" → 점수 계산은 Rule-based, LLM은 자연어 해석만. 슬라이드 4의 분리.
- "Mock data 현실성?" → MVP에선 mock, 실 제품화 시 ThinQ 데이터로 교체 — 둘을 슬라이드에 명확히 분리.
- "ML 모델은 언제 학습?" → 2주차 (5/20~26) 박주상이 plan-mode로 진행. UCI ADL 1순위 후보.
