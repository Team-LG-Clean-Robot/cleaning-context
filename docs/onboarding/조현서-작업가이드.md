## 너의 직무 — Research Contributor (외부 증거·자료 공급자)

**한 줄**: 시장·경쟁·user voice·페르소나에 대한 raw 자료를 모아 **김준성(사업계획서 owner)에게 hand-off**. 그리고 멘토·심사위원 예상 Q&A를 보강.

- **소유**: `docs/research/*.md` (시장 통계·경쟁사 사양·사용자 정성 리뷰·페르소나 raw 자료 — 출처·인용 URL 필수) · 멘토·심사위원 예상 Q&A 10종 (`docs/DEMO_SCRIPT.md §Q&A`)
- **소유 X**: `BUSINESS_PLAN.md` 본문 직접 작성 X (김준성이 너의 자료를 받아 통합·재작성) · 코드·디자인 · 학습용 raw 데이터 (박주상)
- **성공 지표**: 김준성이 "자료 없어서 사업계획서 못 씀" 상황 0건 + 발표 시 멘토 질문 80%+ 즉답 가능 (출처 인용)

핵심 원칙: **너는 자료 공급자**. 글 통합·재작성은 김준성. AI가 던지는 답을 그대로 복붙 X — 인용 URL 확인 후 정리. 출처 없는 숫자는 김준성이 못 씀.

## 작업 흐름 (Hand-off 구조)

```
너 (raw 자료 수집)
     ↓ docs/research/*.md PR
김준성 (사업계획서 본문에 통합·재작성)
     ↓ BUSINESS_PLAN.md PR
전유성 (검토·머지)
```

너의 PR은 김준성을 막지 않게 **빨리·자주** 올리기. 큰 reports 1개보다 작은 자료 PR 여러 개가 나음.
