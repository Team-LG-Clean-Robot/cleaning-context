## ML 검증 이중 구조 (발표 자료용)

발표에서 "합성 데이터 99%면 Rule 복제 아니냐?" 질문 대비.

### v1 — 실제 데이터 검증 (CASAS hh106)

| 항목 | 값 |
|---|---|
| 데이터 | Washington State Univ. 스마트홈, 수개월 실측 20만 건 |
| 라벨 | 36종 활동 (Cook, Sleep, Enter_Home 등) → 우리 8 이벤트 매핑 |
| 모델 | RandomForest, 5-fold CV |
| **정확도** | **85.1%** (Rule-based 55% 대비 +30%p) |
| 의미 | 실데이터에서도 ML이 생활 맥락 추론 가능함을 검증 |
| 한계 | CASAS는 모션 센서만 → 센서 의미(door_lock open/close) 구분 불가 |

### v2 — 파이프라인 검증 (IoT 합성 데이터)

| 항목 | 값 |
|---|---|
| 데이터 | 12종 IoT 센서 합성 3,600건 (복합 이벤트 포함) |
| 모델 | OneVsRest(RandomForest), multi-label |
| **F1** | **99.3%** (5-fold CV) |
| 의미 | 우리 센서 형식에서 ML 파이프라인이 end-to-end 작동함을 검증 |
| 한계 | 합성 데이터이므로 실제 가정 환경의 노이즈·예외 미반영 |
