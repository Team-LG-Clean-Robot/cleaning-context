## 너의 역할

총괄 + 백엔드 + LLM + 배포 + 발표 스토리 + 멘토 커뮤니케이션. **3인 hand-off 게이트키퍼**.

- **백엔드**: FastAPI · Pydantic v2 · 점수 엔진 · LLM 캐시 · `/api/simulate` · `/api/infer-events` · `/api/ask`
- **배포**: Render (백) + Vercel (프론트) — `main` push 시 자동
- **모바일 통합**: Flutter 앱 ↔ 백엔드 스키마 sync (모델은 박주상/조현서가 못 건드림)
- **멘토 커뮤**: 1차 ✅ · 2차 일정 잡기 · 피드백 → 액션 변환
