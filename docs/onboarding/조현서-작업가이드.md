# 조현서 — Research Contributor

## 직무
시장·경쟁·user voice·페르소나에 대한 raw 자료를 모아 **김준성(사업계획서 owner)에게 hand-off**. 멘토·심사위원 예상 Q&A 보강.

## 메인 산출물
- `docs/research/*.md` — 시장 통계·경쟁사 사양·사용자 정성 리뷰·페르소나 raw 자료 (출처·인용 URL 필수)
- `docs/DEMO_SCRIPT.md §Q&A` — 멘토·심사위원 예상 Q&A 10종

## 작업 영역
| 영역 | 내용 |
|---|---|
| 시장 통계 | 한국 로봇청소기 시장 규모·CAGR·점유율 |
| 경쟁사 | LG ThinQ·삼성 비스포크·로보락 사양·가격·전략 |
| 페르소나 | 30대 맞벌이·반려견·IoT 보유자 raw 자료 (nvidia nemotron persona dataset 활용 예정 — 별도 지시받음) |
| User voice | 한국 사용자 리뷰·블로그 — "자율모드 끄고 수동 회귀" 신뢰 격차 정성 증거 |
| 멘토 Q&A | 예상 질문 10종 + 답변 초안 (`이미 LG가 하는 거 아냐?` 같은 약점 포함) |

## 소유 / 소유 X
- **소유**: raw 자료 수집·정리 + Q&A 보강
- **소유 X**: `BUSINESS_PLAN.md` 본문 직접 작성 X (김준성이 너의 자료 받아 통합·재작성) · 코드·디자인 · 학습용 raw 데이터 (박주상)

## Hand-off
```
너 (raw 자료 수집)
     ↓ docs/research/*.md PR (작게 자주)
김준성 (사업계획서 본문에 통합·재작성)
     ↓ BUSINESS_PLAN.md PR
전유성 (검토·머지)
```

김준성을 막지 않게 **작게 자주** PR. 큰 reports 1개보다 작은 자료 PR 여러 개.

## 성공 지표
- 김준성이 "자료 없어서 사업계획서 못 씀" 0건
- 발표 시 멘토 질문 80%+ 즉답 가능 (출처 인용)
- Q&A 10종 완성

## 원칙
출처 인용 필수. AI가 던지는 답을 그대로 복붙 X — 인용 URL 확인 후 정리. 출처 없는 숫자는 김준성이 못 씀.
